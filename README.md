# Omar Karani Portfolio

Personal portfolio for Omar Karani, AI and marketing strategist based in Nairobi, Kenya.

## Sections

- Story
- Experience
- Impact
- Testimonials
- Contact

## Tech

- HTML, CSS and JavaScript
- Responsive layouts for mobile, tablet and desktop
- Reduced-motion support
- External fonts and animation libraries may require internet access

## Run locally

Open `index.html` in a browser. No build step is required.

## Deploy

For GitHub Pages, open **Settings > Pages**, select **Deploy from a branch**, choose `main` and the root folder, then save.

## Responsive checks

Check these viewport sizes before release:

- Phone: 360 x 800, 390 x 844
- Tablet: 768 x 1024, 1024 x 768
- Desktop: 1280 x 800, 1440 x 900

Confirm navigation, contact links, image loading, animations, and horizontal overflow at each size.
